# ️ Mirror Lake Login

A modern, responsive login page featuring a stunning glassmorphism design over a serene nature background. Built with pure HTML and CSS to demonstrate advanced backdrop-filter effects and clean UI principles.

## ✨ Features

-   **Glassmorphism Design:** Advanced use of `backdrop-filter: blur()` and semi-transparent borders for a realistic frosted glass effect.
-   **Responsive Layout:** Fully adaptive design that looks great on desktops, tablets, and mobile devices.
-   **Interactive Inputs:** Floating labels and focus animations for an enhanced user experience.
-   **Nature Aesthetic:** High-quality landscape background creating a calm and immersive atmosphere.
-   **Pure CSS:** No external frameworks or JavaScript dependencies; lightweight and fast.

## 🛠️ Tech Stack

-   HTML5
-   CSS3 (Flexbox, Backdrop Filter, CSS Variables)
-   Font Awesome (for icons)
